# Roadmap

StoreCanvas is intentionally free and local-first. This roadmap is a transparent direction for contributors, not a promise of dates.

## Now

- Make connected multi-screen storytelling reliable at export time.
- Keep independent device slots independent unless linking is explicitly enabled.
- Improve the quality and accessibility of templates, palettes, copy controls, and editor movement.
- Make local JSON projects and browser backups easy to understand and recover.

## Next

- Add more device anatomy and export presets without coupling captures to a single frame.
- Expand locale-aware copy review and accessible contrast guidance.
- Make template and palette authoring easier for contributors through documented fixtures and visual regression coverage.
- Add stronger automated supply-chain and accessibility checks as the public repository grows.

## Exploring

- Optional connectors for more storefront metadata sources.
- A versioned asset manifest that can describe licensed team-owned assets without uploading them.
- More expressive connected artwork and motion-safe presentation treatments.

Ideas are welcome in [GitHub Discussions](https://github.com/luislucatero21/storecanvas-studio/discussions). Proposals should preserve local ownership, a no-monetization product boundary, and a deterministic export path.
