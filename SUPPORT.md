# Support

StoreCanvas is maintained as a free, local-first open-source project.

For usage questions, setup problems, or ideas:

1. Search existing [issues](https://github.com/luislucatero21/storecanvas-studio/issues) and [discussions](https://github.com/luislucatero21/storecanvas-studio/discussions).
2. Start a discussion for a question or workflow idea.
3. Open an issue when you have a reproducible bug, including the runtime, browser, Node.js version, and smallest safe reproduction.

Remove private screenshots, project JSON, API keys, downloaded App Store assets, and personal data before sharing logs or screenshots. Security concerns belong in [SECURITY.md](SECURITY.md), not in public support channels.
